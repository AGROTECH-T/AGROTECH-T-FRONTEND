# AGROTECH-T-FRONTEND

Interfaz de AGROTECH-T en React, TypeScript y Vite. El acceso usa neomorfismo y la paleta verde de una sola tonalidad.

```bash
npm install
copy .env.example .env.development
npm run dev
```

Abre `http://localhost:5173`. La API esperada es `http://localhost:8090`.

Repositorio: https://github.com/AGROTECH-T/AGROTECH-T-FRONTEND
